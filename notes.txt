This will be a Multi-Node setup.
We are creating the following:
    Control Node - 1
    Worker Node(s) - 2

Commands to bootup k8s-clust instances via AWS CloudFormation:

*Follow the same order*  

1. Cluster network:
    ./run_aws_cfm.sh c -t network/CreateVPC_PublicSubnet.yaml -n k8s-clust-net

2. Cluster Control Node:
    ./run_aws_cfm.sh c -t instances/CreateEC2Inst_EBSVol_KeyPair-NoS3.yaml -n k8s-clust-mast-01

3. Cluster Worker Node:
    ./run_aws_cfm.sh c -t instances/CreateEC2Inst_EBSVol_KeyPair-Worker1.yaml -n k8s-clust-work-01
    ./run_aws_cfm.sh c -t instances/CreateEC2Inst_EBSVol_KeyPair-Worker2.yaml -n k8s-clust-work-02

To destroy resources :

*Follow the same order* 

1. Cluster Worker Node:
    ./run_aws_cfm.sh d -n k8s-clust-work-01
    ./run_aws_cfm.sh d -n k8s-clust-work-02
2. Cluster Control Node:
    ./run_aws_cfm.sh d -n k8s-clust-mast-01
3. Cluster network:
    ./run_aws_cfm.sh d -n k8s-clust-net


kubectl commands reference:

1. To get pods which have unhealthy containers but Running (e.g. 1/2 READY)
- kubectl get pods -o json | jq '.items[] | select(.status.containerStatuses[].ready == false) | .metadata.name'
